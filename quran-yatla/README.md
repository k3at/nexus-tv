# قرآن يتلى

موقع لقراءة القرآن الكريم، سماعه، تفسيره، مع أوقات الصلاة، اتجاه القبلة، الأحاديث النبوية، الأذكار والأدعية.

## المزايا

- قراءة القرآن - صفحة مصحف طبعة مجمع الملك فهد + عرض عمودي للآيات
- استماع القرآن - قائمة كاملة بالقراء
- تفسير ابن كثير لكل آية
- أوقات الصلاة حسب الموقع
- اتجاه القبلة بالبوصلة
- الأحاديث النبوية
- الأذكار والأدعية
- فهرس ذكي للسور والأجزاء
- حفظ مكان التوقف تلقائياً
- عداد الصفحات المقروءة
- أوضاع القراءة: نهاري، ورقي دافئ، ليلي داكن
- دعم PWA والعمل بدون إنترنت

## التطوير

```bash
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000)
